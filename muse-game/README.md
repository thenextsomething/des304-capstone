# MUSE: the interactive game (secondary artefact)

Browser-based narrative game, V2, built in Claude Code. Set inside a fake chat interface in Auckland 2035: the player is a creative making a short film, talking to an AI companion called MUSE, choosing at every decision point whether to lean on the AI or trust themselves. Five endings, from The Purist to The Ghost, driven by a leanScore (0 to 5). The UI corrupts as the player cedes control.

Full concept and V2 feature list: `../concept-notes/COMPASS_CONCEPT_AND_STATUS.md`, Section 8.

Naming note: MUSE is the AI character in this game. The wearable in the film is Compass. Same project world, different artefacts.

To run: open `index.html` in a browser. All dialogue and branching live in `story.js` so the writing can be edited without touching game logic (`game.js`).
